# MRUHacksMusicPlayer
We built a basic in-browser audio file player using HTML,CSS, and JavaScript. 
The user will upload an audio file (MP3) from their computer, will be able to scroll through their songs, see the file name being displayed, and turn the volume up and down. 
The project is based off of Apples old iPod design "REVITALIZING" it into a digital form, giving it a new life and allowing users to re-live the early 2000's.
<br>(You must have an MP3 file to play/upload)
